# ☁️ Cloud Cost Comparator

## Інформаційна система для підбору розподілених технологій за заданими критеріями

### Опис проекту

Дипломна робота на тему: **"Інформаційна система для підбору розподілених технологій за заданими критеріями"**

# 🌐 Система Порівняння Вартості Хмарних Технологій

Веб-застосунок для автоматизованого порівняння вартості віртуальних машин на платформах Azure, AWS та Google Cloud Platform з використанням методу багатокритеріального аналізу TOPSIS.

## ✅ ОНОВЛЕНО: Реальні Ціни (Жовтень 2025)

**Система використовує реальні ціни з офіційних калькуляторів станом на жовтень 2025 року.**

### Точність Даних:
- ✅ **Базові ціни**: Оновлені з Azure/AWS/GCP калькуляторів (точність ±5-10%)
- ✅ **Reserved Instances**: Знижки з офіційної документації (Azure: 41-60%, AWS: 38-59%, GCP: 37-55%)
- ✅ **Регіональні множники**: Базовані на реальних співвідношеннях
- ✅ **Всі джерела**: Задокументовані в коді та PRICING_UPDATE_2025.md

### Що це Є:
- ✅ Демонстрація **методології порівняння** хмарних платформ
- ✅ Імплементація **TOPSIS алгоритму** для багатокритеріального аналізу
- ✅ Показ впливу **Reserved Instances** на довгострокову вартість
- ✅ **Порівняльний аналіз** з точністю достатньою для прийняття рішень

### Обмеження:
- ⚠️ **НЕ** 100% точні ціни (різниця через SKU варіації, Enterprise discounts)
- ⚠️ **НЕ** враховує всі фактори (licensing, networking, support, promotional offers)
- ⚠️ **НЕ** перевіряє доступність VM у конкретних регіонах
- ⚠️ **НЕ** замінює консультацію з cloud architects для production рішень

### Алгоритм TOPSIS

Система використовує метод **TOPSIS** (Technique for Order of Preference by Similarity to Ideal Solution) для багатокритеріального аналізу:

1. Нормалізація критеріїв (вартість, надійність, продуктивність, підтримка)
2. Зважування критеріїв згідно з їх важливістю
3. Розрахунок відстані до ідеального та найгіршого рішення
4. Обчислення підсумкової оцінки для кожного провайдера
5. Ранжування провайдерів
